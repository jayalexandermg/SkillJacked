# Content Tier Diagnostic

Classify writing as Commodity, Personality, or Original to decide whether it's AI slop or worth publishing.

## Quick Start
Before publishing any draft, ask: "Could literally anyone with access to the same facts have written this?" IF yes, THEN it's Commodity tier — rework before shipping. IF the piece only works because of who wrote it (their experience, voice, specific stance), THEN it's Personality or Original tier — safer to ship.

## Core Workflow

**Trigger**: User asks "is this good content?", "why does my writing sound like AI?", or wants a draft audited before publishing.

1. **Read the draft and identify the core claim/insight.**
   - Ask: is this claim generic advice available anywhere, or a specific, earned perspective?

2. **Check pronoun framing.**
   - IF the piece is framed as "you should do X" / "here's how to do X" (generic instruction), THEN it leans Commodity — it reads like advice anyone could give.
   - IF the piece is framed as "I did X" / "here's what happened when I..." (first-person, lived experience), THEN it leans Personality or Original — it's harder to replicate because it's tied to a specific person's experience.

3. **Classify into one of three tiers:**
   - **Commodity**: Generic, interchangeable content. Same insight/structure could be produced by anyone or any AI with the same prompt. No unique perspective, no personal stake.
   - **Personality**: Content infused with the writer's specific voice, stance, or experience — not swappable with another writer's version even if the underlying facts are similar.
   - **Original**: Content that introduces a genuinely new idea, framework, or angle not already circulating — the highest bar, hardest to fake with AI alone.

4. **Decide next action based on tier:**
   - IF Commodity → rewrite using first-person specifics, real anecdotes, or a distinct opinion before publishing.
   - IF Personality → check the voice/experience is authentic and specific enough to survive scrutiny.
   - IF Original → verify the idea is actually novel (not just restated commodity content in confident language).

## Techniques

- **The "Anyone Else" Test**: Ask "Could a different writer with access to the same information have produced this exact piece?" IF yes → Commodity.
- **Pronoun Swap Test**: Rewrite a "you" sentence as "I." IF the sentence becomes awkward or requires fabricating personal detail, THEN the original was likely commodity/generic advice dressed up as insight. IF the "I" version reads naturally and adds credibility, THEN the content is tied to real experience (Personality/Original).
- **Specificity Check**: Generic advice ("you should build in public") is Commodity. The same advice with a specific personal detail ("I built in public for 18 months and lost 3 followers before gaining traction") shifts toward Personality.

## Anti-Patterns

- NEVER publish a draft framed entirely in generic "you should" language without checking if it's swappable with anyone else's content — this is the hallmark of AI slop.
- NEVER assume first-person framing alone makes content Original — "I" framing can still be Commodity if the underlying insight is generic and the personal detail is thin or fabricated-sounding.
- NEVER skip the tier classification step before publishing just because a draft "sounds smart" — confident tone can mask Commodity-tier content.

## Edge Cases & Error Handling

- IF a draft mixes tiers (starts with generic advice, ends with a personal story), THEN classify by the dominant framing and rework the weaker sections to match the stronger tier.
- IF unsure whether an idea is truly Original vs. just Personality, THEN default to treating it as Personality (safe, credible) rather than overclaiming novelty.
- IF the writer has no genuine personal experience to draw on for a topic, THEN do not force first-person framing — either find a real angle or accept the piece may need external sourcing/interviews to escape Commodity tier.
