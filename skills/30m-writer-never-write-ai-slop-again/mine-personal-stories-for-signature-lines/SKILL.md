# Mine Personal Stories for Signature Lines

Turn one true personal moment into a single, exact-wording line that gets reused hundreds of times to build audience recognition.

## Quick Start
1. List 3-5 odd, specific, true details from your life (a hobby, an obsession, a weird job, a formative failure).
2. Turn each into one candidate sentence, written exactly as you'd say it out loud.
3. Post each candidate in a low-stakes place (comment, short post, opening line of an article) and watch which one gets disproportionate reaction.
4. Once one lands, STOP rewriting it. Repeat that exact sentence, word-for-word, as the opening/hook across future content.

## Core Workflow
**Trigger: "I don't have anything interesting to write about."**
→ Do not brainstorm generic topics. Instead, mine autobiographical specifics — the more oddly specific, the better (e.g., "I used to play World of Warcraft for 12 hours a day"). Specificity is what makes a line testable and memorable; generic statements cannot be repeated because they don't stick.

**Trigger: "How do I make my story stick?"**
→ Run the test-observe-repeat loop:
1. **Draft** the story as a single, tight sentence (not a paragraph).
2. **Test** it live — publish it in a real, low-risk context.
3. **Observe** the reaction (comments, replies, engagement) rather than guessing.
4. **Lock** the exact phrasing once it resonates. IF a version of the line gets noticeably more reaction than your other attempts, THEN treat that exact wording as final — do not "improve" it further.
5. **Repeat** the locked line verbatim across many future pieces of content (bios, hooks, intros, pitches) so the audience starts to associate that specific sentence with you.

## Techniques
- **The Quora Loop**: Post a candidate personal-story sentence in a forum/comment context (Quora-style). If it gets replies/upvotes/reactions, that's signal the phrasing works. Reuse that same sentence — not a paraphrase — as your go-to hook going forward.
- **Repetition builds association**: IF you change the wording each time you tell the story, THEN the audience never builds a strong association with it. IF you repeat the exact same sentence hundreds of times across different content, THEN it becomes a recognizable signature that readers connect to you specifically.
- **Specificity test**: Before testing a line, check — could this sentence only be said by me? IF yes, it's a strong candidate. IF it could apply to anyone, discard it and mine for a more specific detail.

## Anti-Patterns
- NEVER rewrite or "polish" a signature line after it has already tested well — altering the wording breaks the repetition/association effect you're building.
- NEVER settle for a vague or generic personal anecdote ("I've always loved learning") — it can't be tested for resonance and won't stick as a repeatable line.
- NEVER treat this as a one-time exercise — a line only becomes a signature through repeated, identical reuse across many pieces of content.

## Edge Cases & Error Handling
- IF no candidate line gets a strong reaction on first test, THEN mine a more specific/odd detail rather than assuming the format is wrong — under-specific stories are the most common failure mode.
- IF you're tempted to use a different phrasing "for variety," THEN resist — variety here undermines the goal, which is audience recognition through exact repetition, not fresh writing each time.
