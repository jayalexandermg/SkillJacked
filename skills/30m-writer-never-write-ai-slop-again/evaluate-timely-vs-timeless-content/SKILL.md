# Evaluate Content on the Timely-vs-Timeless Spectrum

Decide what's worth creating by classifying an idea's value across short, medium, and long-term horizons before investing effort.

## Quick Start
Before writing/scripting anything, ask: "If this performs poorly in the first 48 hours, will it still have value in 6 months or 3 years?" If yes → treat as timeless investment, judge success on long-term compounding, not immediate view count. If no → treat as timely, judge success on immediate distribution/reach only.

## Core Workflow
1. **Identify the idea's horizon.** When evaluating any content idea, ask: is this tied to a current event/trend (timely) or a durable insight/principle (timeless)?
2. **Set the correct success metric BEFORE creating.**
   - IF timely → THEN measure success by short-term reach/distribution (did it ride the wave while relevant).
   - IF timeless → THEN measure success by whether it keeps getting discovered/reused over months or years, NOT by day-one performance.
3. **Check for commodity content.** IF the core idea is a widely-repeated, generic statement (e.g., "eat healthy to lose weight"), THEN recognize it has low differentiation value — it's not "plagiarism," it's just commodity content that won't stand out regardless of horizon.
4. **Decide investment level accordingly.**
   - IF timely and low-effort → THEN produce quickly, prioritize speed over depth, expect quick decay.
   - IF timeless and high-effort → THEN accept slower/quieter initial distribution as normal, do not judge it a failure early.
5. **Avoid category confusion.** NEVER apply timely-content success metrics (viral/meme-level short-term spread) to timeless work — this is a category error that leads to abandoning good long-term work too early.

## Techniques
- **The "commodity sentence" test:** Ask if this exact idea/phrasing has been said by "a gazillion people" already. If yes, it's commodity — fine for timely/volume content, but won't carry timeless weight on its own; needs a unique angle, mechanism, or proof to become durable.
- **AI-abundance filter:** Since AI enables infinite content creation on any topic at any volume, explicitly ask "what is worth writing in the first place?" as a gating question before producing — use the timely/timeless classification as the filter.

## Anti-Patterns
- NEVER expect timeless, evergreen work to get meme-level or trend-level short-term distribution — that's the wrong yardstick and will produce false negative judgments about quality work.
- NEVER treat a commodity sentence/idea as inherently valuable just because it's "true" — truth alone doesn't equal differentiation or worth-writing status.
- NEVER conflate repeating a common idea with plagiarism, and don't conflate producing a common idea with producing something noteworthy — commodity content is a distinct category from both.

## Edge Cases & Error Handling
- If content mixes both horizons (a timely hook wrapped around a timeless principle), evaluate each layer separately: judge the hook's short-term pull and the underlying idea's long-term durability independently.
- If unsure which category an idea falls into, default to asking whether the content's relevance depends on a specific moment in time (news, trend, event) — if removing that moment kills the content's relevance, it's timely.
